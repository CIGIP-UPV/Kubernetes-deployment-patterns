Helm Repository

Kubernetes Deployment Patterns

Helm repository for evaluating ROS 2 deployment patterns on Kubernetes: monolithic containers, microservices, dynamic loading, and overlay workspaces.

This repository is intended to be consumed from Helm-compatible tooling such as Rancher and the Helm CLI.

Open index.yaml View source repository

Available Charts

  • ros2-monolithic: single-container ROS 2 application with camera, YOLO, and detections.
  • ros2-microservices: decoupled camera and YOLO services.
  • dynamic-loader: runtime-loadable YOLO inference via FastAPI.
  • ros2-overlay: base workspace plus overlay workspace deployment.

Usage

helm repo add tesis-patterns https://cigip-upv.github.io/Kubernetes-deployment-patterns/charts
helm repo update
helm search repo tesis-patterns
